Data_Analysis2
📌 Overview

This repository contains a collection of data analysis, machine learning, forecasting, and business intelligence projects developed using Python. The projects demonstrate practical implementation of data preprocessing, visualization, predictive modeling, clustering, and dashboard development using real-world datasets.

Each project follows a structured workflow including:

Data Cleaning and Preprocessing
Exploratory Data Analysis (EDA)
Model Building
Evaluation and Visualization
Business Insights and Interpretation
🏦 Task 1: Term Deposit Subscription Prediction

This project predicts whether a bank customer will subscribe to a term deposit based on marketing campaign data.

The workflow includes data preprocessing, categorical feature encoding, and training classification models such as Logistic Regression and Random Forest. Model performance is evaluated using Confusion Matrix, F1-Score, and ROC Curve. SHAP Explainable AI is also used to interpret model predictions and understand customer behavior patterns.

🛍️ Task 2: Customer Segmentation Using K-Means Clustering

This project focuses on grouping customers based on their spending habits and annual income.

Exploratory Data Analysis (EDA) is performed to understand customer behavior patterns. K-Means Clustering is applied to create customer segments, while PCA visualization helps display clusters clearly. Business and marketing strategies are proposed for each identified customer group.

⚡ Task 3: Energy Consumption Time Series Forecasting

This project predicts short-term household energy consumption using historical electricity usage data.

The workflow includes time-series preprocessing, feature engineering, and forecasting using ARIMA, Prophet, and XGBoost models. Model performance is compared using MAE and RMSE metrics, and forecast visualizations are created to compare actual and predicted energy usage.

💳 Task 4: Loan Default Risk with Business Cost Optimization

This project predicts the likelihood of loan default and optimizes prediction thresholds using business cost analysis.

The dataset is cleaned and preprocessed before training models such as Logistic Regression and CatBoost. Business costs for false positives and false negatives are defined to minimize financial risk. Feature importance analysis is also performed to identify major factors affecting loan default.

📊 Task 5: Interactive Business Dashboard in Streamlit

This project involves building an interactive business intelligence dashboard using Streamlit.

The dashboard analyzes sales, profit, and customer performance using the Global Superstore Dataset. Interactive filters for Region, Category, and Sub-Category allow users to explore data dynamically. KPI charts display Total Sales, Profit, and Top Customers by Sales to support business decision-making.
